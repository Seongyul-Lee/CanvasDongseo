# Domain

| 항목 | 내용 |
|---|---|
| 독자 | 개발자 본인, 후속 문서·구현을 돕는 AI 에이전트 |
| 근거 | [System Architecture](../02_system_architecture.md), [PRD](../01_prd.md) |

> **이 문서의 역할**: domain 레이어의 엔티티와 업무 규칙을 정한다. 구체 목록은 Functional Spec과 유스케이스를 정할 때 채운다.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 링 | Entities |
| crate | `domain` |
| 의존할 수 있는 것 | 기초 crate만. 외부 crate는 `jiff`(시각 값 타입)만 쓴다 |

## 2. 원칙

- UI·프레임워크·HTTP·키체인·AI·OS API를 모른다.
- **직렬화를 하지 않는다.** `serde`를 쓰지 않는다. 직렬화는 DS DTO, 출력 DTO, ViewModel, IPC 타입이 맡는다.
- 학교·학습에 관한 업무 규칙만 둔다. 학교 세션 갱신 시점 같은 인프라 정책은 [data_access/shared](data_access/README.md)에 둔다.
- 순수 함수와 값 타입으로 쓰고, 단위 테스트로 고정한다.

## 3. 엔티티 (후보)

| 과제, 제출 | Canvas | 미제출 표현은 REST·GraphQL 차이를 DS에서 맞춘 뒤 들어온다 |

## 4. 업무 규칙 (후보)

- 이번 주 할 일 판정(마감, 미완료 차시, 미제출 과제)
- 차시 완료 판정(`completion_determinable`이 참일 때만 `completed`를 믿는다)
- 출결 집계(출석·지각·결석·미결)

### 4.1 슬라이드 판정 (강의 동영상 → 슬라이드 PDF)

앱이 신뢰하는 판정 로직이라 안쪽 링에 둔다. 학교 업무 규칙(과제·출결)과 성격이 다른 영상 처리 정책이므로 **`domain::slides` 모듈로 분리**하고, 다른 모듈과 서로 참조하지 않는다. 입력은 회색조·컬러 프레임 버퍼(바이트 배열과 크기)뿐이고, 디코딩·OCR·파일은 모른다. 외부 crate 없이 순수 함수로 쓴다. 처리 흐름은 [learning_adapters §2](06_learning_adapters.md).

| 규칙 | 내용 (기준값은 2026-10-26 운영체제 강의 실측) |
|---|---|
| 신호 추출 값 | 1초에 한 장, 폭 320, 회색조. 유스케이스가 이 상수를 `FrameDecoder`에 넘긴다(포트에 값을 박지 않는다) |
| 슬라이드 영역 | 시간축 열·행 밝기 중앙값으로 슬라이드 영역을 찾는다(좌우 검은 띠, 펜 도구 위젯 제외) |
| 시그니처 | 폭 320 프레임의 슬라이드 영역을 8px 블록으로 나눠 블록별 밝기·에지 |
| 전환 | 이전 프레임과 비교해 바뀐 블록 비율이 0.2를 넘으면 전환. 1초 미만 깜빡임은 이웃 구간에 합친다 |
| 재등장 묶음 | 내용 있는 블록의 일치율이 0.55 이상이면 같은 슬라이드로 묶는다 |
| 후보 | 묶음마다 서로 다른 화면 상태를 최대 12장. 구간 첫·끝 프레임은 꼭 넣는다. 여기까지는 회색조 축소 프레임으로 정한다 |
| 점수 | **원본 해상도 컬러 후보**로 매긴다(채도를 보므로 회색조로는 매길 수 없다). 완전성(애니메이션으로 늦게 나타나 끝까지 남는 내용을 포함하는가), 원본성(펜 색 픽셀이 적은가). 펜 색 = 채도 > 0.35이고 밝기 > 120 |
| 확정 | **완전성이 최대치의 95% 이상인 후보 중 원본성이 가장 높은 장면을 자동으로 확정한다.** 사람이나 AI의 검토를 거치지 않는다 |
| 쪽 순서 | 묶음이 처음 나온 시각 순. 다시 나온 시각은 타임스탬프에 함께 적는다 |

- 정답 세트(사용자가 고른 묶음 10개 이상)로 회귀 테스트를 둔다. 기준값을 바꾸면 이 테스트로 확인한다.

### 4.2 학습 결과물 이름 규칙

| 규칙 | 내용 |
|---|---|
| 키 | 학기, 과목, 종류(동영상·슬라이드·스크립트), `{NN}주차_{M}차시_{제목}` |
| 짝 | 동영상·슬라이드 PDF·스크립트는 키에서 종류만 다르면 짝이다. 학습 기능이 이 규칙으로 주차별 자료를 모은다 |
| 제목 정리 | 경로 구분자·`..`·제어 문자를 뺀다 |

- 키를 실제 경로로 바꾸는 일은 `LearningOutputRepository` 구현([application §4.3](02_application.md))이 맡는다. domain은 파일 시스템을 모른다.

## 5. 이웃 레이어와의 계약

- application은 엔티티와 규칙을 쓰고, 바깥으로는 출력 DTO로 바꿔 내보낸다(S10).
- 출력 포트 구현(data_access)이 DS DTO를 엔티티로 바꿔 넘긴다.
